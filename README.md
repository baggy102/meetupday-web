# MeetupDay

B2B 매칭 플랫폼 - 스타트업 간 협업, 밋업 일정 관리 및 기술적 지원을 제공하는 웹 애플리케이션

## 주요 기능

- 사업자등록 인증 기반 회원가입
- 산업별 회사 분류 (IT, 마케팅, 헬스케어, AI)
- 회사 정보 조회 및 매칭 신청
- 밋업 일정 캘린더 관리
- 매칭 알림 및 수락 시스템
- 대시보드 기반 진행 관리

## 기술 스택

- Next.js 14
- TypeScript
- Tailwind CSS
- NextAuth.js
- React Hook Form
- Zod

## 시작하기

```bash
npm install
npm run dev
```
